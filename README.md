# clgam (CL-GAMM)

Composite link **generalized additive mixed models** (CL-GAMM) for **areal count data**.

The package supports:
- **Area-to-area disaggregation** from coarse Poisson observations to a **nested fine support** via a **composition matrix** `C`.
- Spatial structure using **anisotropic P-spline smooths**.
- Optional **fine-scale covariates** via nonlinear smooths.
- Estimation using PIRLS with **separation of penalties (SOP/SAP)**.

No proprietary data are included. The included examples/tests use synthetic data generated by `simulate_ata()`.

## Install

From this local clone (source install):

```r
install.packages(".", repos = NULL, type = "source")
```

In the package repo you can also install from GitHub when published:

```r
# remotes::install_github("idaejin/clgam")
```

## Quick start

```r
library(clgam)

dat <- simulate_ata(
  n_coarse = 16,
  n_fine_per = 8,
  seed = 1,
  include_covariate = TRUE
)

fit <- clgam(
  y = dat$y,
  coords = cbind(dat$x1, dat$x2),   # fine centroids
  C = dat$C,
  exposure = dat$efine,
  smooth = dat$nlcovfine,
  knots = c(10, 10),
  knots_nl = 12
)

plot(fit, which = 1, sf_fine = dat$sf_fine, sf_coarse = dat$sf_coarse)
plot(fit, which = 4, g_true = dat$g_true)
```

`simulate_ata()` constructs a nested Voronoi geometry on `[0,1]×[0,1]` (via `sf`).

## Legacy entry points

The legacy paper names are retained:
- `pois_SAP`, `pois_incat_SAP`, `pois_PCLM_latent`
- `clgam_contrast()` is an alias of `pois_incat_SAP`

## Compile / performance options

The SOP hot path can use compiled kernels:

```r
options(clgam.use_rcpp = FALSE)  # toggle compiled SOP kernels
```
